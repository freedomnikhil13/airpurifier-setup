1 Connect the purifier

Plug the purifier's small circuit board into this laptop with the USB cable. Then click Connect and pick the item that says CP210x, USB to UART, CH340 or COM…, then click Connect in that box.

Nothing in the list? Try another USB cable (some only charge), or another USB port. On Windows the driver can take a minute to install the first time, then try again. If it still doesn't appear, install the CP210x driver (Windows: "CP210x Windows Drivers").

"Failed to connect"? Press and hold the BOOT button on the board, click Connect again, and let go once it says connected.

2 Save a backup

Saves the purifier's current software to this laptop first, so nothing can be lost. Takes about 1–2 minutes.

3 Install the new software

About 1 minute. Don't unplug while the bar is moving.

4 Check the screen

Look at the purifier's screen now.

It should show the words SCREEN TEST on a black background, with three boxes: RED, GREEN, BLUE. Which one is true?

5 Connect to home WiFi

6 Finished
